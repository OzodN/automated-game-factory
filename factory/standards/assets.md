# Asset standards (AS)

| ID | Level | Rule | Check |
|---|---|---|---|
| AS-01 | MUST | Every third-party file enters a game only via `factory assets pull`, from a pack whose license is **verified** (license text inspected, evidence recorded). | cli, review |
| AS-02 | MUST | License policy: allowed CC0-1.0, Unlicense, OFL-1.1 (fonts), MIT, Apache-2.0, CC-BY-3.0/4.0 (with attribution). Rejected: any SA (share-alike), NC, ND, GPL, "free for personal use", unknown. | cli (ingest refuses) |
| AS-03 | MUST | `assets/LICENSES.json` and `CREDITS.md` are generated by the CLI and shipped with the release archive; attribution text reproduced exactly. | cli, validator (`--release`) |
| AS-04 | MUST | No third-party copyrighted names, logos, characters or music; no assets ripped from other games. | review |
| AS-05 | MUST | UI icons are drawn (vector) or from licensed icon sets (e.g. Phosphor MIT, game-icons.net CC-BY with credit) — never emoji glyphs. | review |
| AS-06 | MUST | Audio: produced files, ogg + mp3, loudness-normalized (target −16 LUFS music, −14 LUFS SFX peaks ≤ −1 dBTP), music loops seamless; no wav in builds. | validator, review |
| AS-07 | MUST | File names `[a-z0-9_-]` with extension; paths relative. | validator |
| AS-08 | MUST | Budget: build ≤ 25 MB, ≤ 250 files, no file > 10 MB; sprites in atlases ≤ 2048². | validator |
| AS-09 | MUST | One coherent style per game (palette, line weight, perspective, resolution) defined in `design/spec/art-audio.md`; mixed packs harmonized or rejected. | review |
| AS-10 | MUST | Covers and screenshots are real gameplay captures of the release build. | review (release-manager) |
| AS-11 | SHOULD | Prefer the factory library before searching the web; ingest new useful packs so later games reuse them. | review |
| AS-12 | SHOULD | Keep editable sources (SVG, project files) in `assets/src/` (not shipped). | review |
| AS-13 | MUST | An item enters the library only through `factory assets acquire` (remote index) or `factory assets ingest` (manual download), with its source revision (`source_rev`, acquire) and page URL recorded in PACK.json and the catalog. PACK.json is authoritative for verification. | cli |
| AS-14 | SHOULD | Before creating original art or searching the web, search the library, then the remote index (`assets search --remote`), and look at candidates with `assets preview`. | review |

## Source registry (from the user's preferred sources; verify each pack individually)
| Source | Typical license | Notes |
|---|---|---|
| Kenney (kenney.nl, itch.io) | CC0 | Direct downloads; consistent styles. |
| OpenGameArt (Buch, Clint Bellanger, others) | mixed per asset | Filter CC0; CC-BY ok with credit; **reject CC-BY-SA / GPL**. |
| Ansimuz, Pixel Frog (itch.io) | varies per pack (often CC0 or custom) | Read each pack's license; custom "free for commercial use" terms need human review. |
| Oryx Design Lab | free releases vary | Only packs explicitly CC0/compatible. |
| Poly Pizza | CC0 or CC-BY per model | Check each model. |
| AmbientCG | CC0 | Textures/materials. |
| game-icons.net | CC-BY 3.0 (mostly) | Credit each author. |
| Phosphor Icons | MIT | Good UI icon source. |
| OpenMoji / Twemoji | CC-BY-SA / CC-BY | **Excluded** for UI icons (emoji rule 4.3.2; OpenMoji is share-alike). |
| Google Fonts | OFL-1.1 / Apache-2.0 | Self-host the font files; never load from Google. |
| Freesound | per sound (CC0 / CC-BY / CC-BY-NC) | Filter CC0; CC-BY with credit; reject NC. Free API key optional (`FREESOUND_API_KEY`). |
| Incompetech (Kevin MacLeod) | CC-BY 4.0 | Attribution required exactly as specified by the author. |
| Bensound | proprietary free tier | **Excluded** unless a license is purchased and recorded. |
| jsfxr / Bfxr / ChipTone | output is yours | Render to files; UI blips only (rule 3.3.2 gray zone); never as the full soundscape. |
| Indexed `oga-cc0` (HF mirror nyuuzyou/OpenGameArt-CC0) | CC0-1.0 | Remote index source (`assets sync`); search with `--remote`, take with `acquire`; check the live OGA page before `verify` (AS-04). |
| Indexed `oga-cc-by-3` / `oga-cc-by-4` (HF mirrors of OpenGameArt CC-BY 3.0 / 4.0) | CC-BY-3.0 / CC-BY-4.0 | As above; rows without attribution text are refused by acquire; the credit line goes to CREDITS.md on pull. |
| Denylist (`<library>/catalog/denylist.jsonl`, `assets deny`) | — | Remote ids, items or authors found ripped, relicensed or otherwise unusable: search skips them, acquire and pull refuse them. Append-only, with a reason. |
